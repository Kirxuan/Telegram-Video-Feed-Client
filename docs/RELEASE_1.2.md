## VELORA（曜流）1.2

本版本改进频道视频连续播放、移动数据加载和观看界面，提供沿用 1.1.0 正式签名的 ARM64 安装包。

### 更新内容

- 优化移动数据下的分段下载和唯一下一条视频预加载，减少重复请求与切换等待；自动模式优先准备 Telegram 实际提供的省流版本。
- 当前视频播放结束后自动切换下一条，复用既有播放队列；手动操作优先，播放错误仍保留提示。
- 视频简介默认折叠，点击展开；调整进度条位置，改善底部手势操作空间。
- 视频播放期间保持屏幕亮起，暂停或离开页面后恢复系统熄屏策略。
- 改善频道选择、缓存设置和播放器交互；移动数据下缺少省流版本且原画超过 200 MB 时，先确认再加载。

### 安装与升级

- Android 8.0（API 26）或更高版本，仅支持 `arm64-v8a`。
- 从正式版 1.1.0 升级：下载下方 `VELORA-1.2-arm64-v8a.apk`，使用覆盖安装，无需卸载。
- 开发版 Debug APK 与正式版签名不同，不能直接覆盖安装；卸载开发版会清除本地登录、索引和缓存。
- 每位使用者在应用内填写自己的 Telegram API ID/API Hash；正式 APK 不包含构建者的 Telegram 参数。

### 验证与边界

- 本次主机 `test`、`lint`、`:app:assembleRelease` 通过；1815 项测试，0 失败、0 错误、0 跳过。
- 正式 APK 的版本、签名 v2/v3、zipalign、ARM64 ABI、仅两项网络权限及禁用备份检查通过；解包后本机 Telegram 参数扫描为零命中。
- 用户确认当前版本可正式启用。本次发布流程未重新执行模拟器 UI 或真机安装、登录与移动数据回归，这些项目尚未验证。
- 视频加载体验取决于网络、视频码率和预加载是否命中，不保证所有视频都能瞬时起播。
